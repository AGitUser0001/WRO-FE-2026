# Runtime visualizations

This folder stores screenshots and recordings from runtime tools such as RViz. These files are evidence of live sensor, transform, merge, control, or telemetry behavior; they are not CAD renders, vehicle photographs, or illustrative diagrams.

Use descriptive filenames in the form `<subsystem>-<view-or-output>-rviz.png` when applicable. Each image used in the engineering journal must have a caption that states what was displayed and what claim the image supports.
