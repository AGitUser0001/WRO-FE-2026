# VNC

Run:
```bash
sudo nvidia-xconfig --virtual=1920x1080 --allow-empty-initial-configuration --connected-monitor="DFP-0" --metamodes="DFP-0: 1920x1080" --no-use-edid

sudo vi /etc/X11/xorg.conf
```

In the device section, add
```
    Option         "AllowNonEdidModes" "True"
    Option         "ModeValidation" "NoEdidModes, NoHorizSyncCheck, NoVertRefreshCheck, NoMaxPClkCheck"
```

Run:
```bash
mkdir -p ~/.config/autostart
vi ~/.config/autostart/set-resolution.desktop
```

Insert:
```
[Desktop Entry]
Type=Application
Name=Set Resolution
Exec=xrandr --output DP-0 --mode 1920x1080
X-GNOME-Autostart-enabled=true
NoDisplay=false
```

Then, run these commands:
```bash
sudo apt update
sudo apt install vino

cd /usr/lib/systemd/user/graphical-session.target.wants
sudo ln -s ../vino-server.service ./.

gsettings set org.gnome.Vino prompt-enabled false
gsettings set org.gnome.Vino require-encryption false

gsettings set org.gnome.Vino authentication-methods "['vnc']"
gsettings set org.gnome.Vino vnc-password $(echo -n 'password'|base64)

sudo reboot
```

Now you can connect using a VNC client application like Screen Sharing on Mac or RealVNC Viewer.

vnc connect password: <VNC_PASSWORD>
