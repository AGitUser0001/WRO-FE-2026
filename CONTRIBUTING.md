# Contribution Workflow

1. Create a focused branch.
2. Record the requirement, issue, or hypothesis.
3. Make one reviewable change.
4. Add or update tests and documentation.
5. Use a meaningful commit message, for example `control: reduce corner-entry oscillation`.
6. Review code, wiring, CAD, and safety implications before merging.

Do not commit secrets, tokens, personal data, generated caches, or large temporary recordings.
